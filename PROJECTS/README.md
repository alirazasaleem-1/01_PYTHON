# Python Portfolio: Day 30 Milestone

Welcome to my Python repository! This collection showcases the foundational projects I built during my first 30 days of learning Python.

## Projects Overview

| Project | Description | Key Concepts Learned |
| :--- | :--- | :--- |
| **1. Number Guessing Game** | A classic game where the user guesses a random number between 1 and 15. | `random` module, `while` loops, `try-except` blocks. |
| **2. Grocery List Manager** | A tool to manage shopping lists with add, remove, and clear capabilities. | List manipulation, `enumerate`, function design. |
| **3. Smart To-Do List** | A modular task manager that handles user-defined actions in real-time. | Conditional logic, string manipulation, modular functions. |
| **4. File-Based Task Saver** | A persistent task manager that saves and retrieves data from a text file. | File I/O (`a+` mode), persistent data storage. |

## 🚀 Projects

### 1. 📖 Personal Diary (CLI Based)

A simple command-line diary application that allows users to write and read personal entries with timestamps.

**Features:**

* Add daily thoughts and notes
* Automatically saves with date & time
* Read all past entries anytime

**Use Case:**
Useful for journaling, self-reflection, and tracking daily thoughts.

---

### 2. 🌦 Weather Data Fetcher (API Project)

A Python script that fetches live weather data using an API and stores it in JSON format.

**Features:**

* Takes city input from user
* Fetches real-time temperature data
* Saves results into JSON file

**Use Case:**
Can be used in dashboards, automation systems, or weather-based apps.

---

### 3. ✅ Daily Task Automator (JSON + Excel)

A productivity tool that stores tasks along with reminders and saves them in both JSON and Excel formats.

**Features:**

* Captures task, reminder time, and date
* Saves data into JSON file
* Also logs tasks into Excel sheet
* Automatically creates file if not exists

**Use Case:**
Helps in task management, productivity tracking, and data organization.

---

### 4. 🌐 Web Scraper – Wikipedia Data

A web scraping script that extracts structured data (tables) from a Wikipedia page.

**Features:**

* Sends HTTP request to webpage
* Parses HTML using BeautifulSoup
* Extracts tables from page
* Displays partial data

**Use Case:**
Useful for data collection, research, and automation tasks.

---

### 5. 📰 BBC News Headlines Scraper

A script that scrapes latest news headlines from BBC and saves them into a text file.

**Features:**

* Extracts top 5 headlines
* Saves data into text file
* Displays headlines in console

**Use Case:**
Can be used for news aggregation apps or content automation.
